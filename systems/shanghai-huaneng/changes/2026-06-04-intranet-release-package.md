# 变更平台支持内网发布包

- 日期：2026-06-04
- 记录类型：协同说明
- 适用范围：变更平台发布流程

## 本次改动内容

### 1. 新增内网发布说明

平台根目录新增《内网发布说明》，把发布方式从“本机打开文件”梳理为“放到公司内网服务器，通过统一内网地址访问”。

说明里明确了服务器准备、发布包生成、IIS / Nginx 放置方式、默认首页配置和上线后的验证项。

### 2. 新增一键生成内网发布包工具

新增 `tools/build-intranet-release.ps1`，用于把当前平台整理成一份可交付的发布包。

执行后会自动完成：

- 构建上海华能 Demo。
- 把最新 Demo 同步到平台目录。
- 复制平台首页、样式脚本、系统 Demo、变更记录数据。
- 生成 `output/intranet-release/` 发布文件夹。
- 生成 `output/change-platform-intranet-release.zip` 压缩包。

### 3. 发布包只保留访问所需内容

发布包里只保留内网用户访问需要的内容，包括平台入口、系统 Demo、变更记录和静态资源。

源码目录、依赖包、自动化工具和临时截图不会放进发布包，减少体积，也避免把研发工作区直接暴露到内网访问环境。

### 4. 后续更新方式更清晰

以后每次改完 Demo 后，只需要重新生成发布包，再覆盖到内网服务器目录即可。

这让产品、研发、测试看到的是同一个平台地址，不需要反复传文件或让每个人打开本地路径。

## 给运维的发布口径

这是一个纯前端静态站点，请把发布包内容放到内网 Web 服务目录，以 `index.html` 作为默认首页，对外暴露一个 HTTP 内网地址即可。
